Advertising has no product breakdown here The Intentwise export is one row per metric per day, with no ASIN in it. Per-product advertising would need the Sponsored Products placement or advertised-product report.

Conversion is orders per session — Amazon's order-item session percentage. Subscribe & Save orders arrive without a session, so it runs a little high. Margin = price − landed cost − referral fee − fulfilment, before advertising, storage and refunds. Traffic is de-duplicated: Amazon repeats one ASIN's sessions down each of its SKU rows. Weeks run Sunday to Saturday, matching Seller Central. An unfinished period is compared only against the same number of days in the periods it is measured against.
